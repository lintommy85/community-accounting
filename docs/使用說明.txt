社區帳務管理 使用說明
====================

【資料夾結構】
社區帳務管理\
  社區帳務管理.exe      ← 雙擊執行
  使用說明.html         ← 圖文版使用說明（用瀏覽器開啟）
  使用說明.txt
  data\                 ← 第一次執行時自動建立，所有紀錄與設定都存在這裡
    ledger.json         ← 主要資料檔（每次修改自動儲存）
    backups\            ← 每天第一次存檔前自動保留前一版，最多 60 份

【第一次使用】
1. 把「社區帳務管理」資料夾放到電腦上，例如 D:\社區帳務管理（不要放在壓縮檔裡直接執行）。
2. 雙擊「社區帳務管理.exe」。第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」，
   請按「其他資訊」→「仍要執行」。防毒軟體（例如 PC-cillin）若封鎖，請把「社區帳務管理」資料夾加入例外清單。
3. 系統會在背景執行並自動開啟瀏覽器，不會有其他視窗。第一次開啟會播放使用說明動畫（之後可在「基本設定」重新播放）。
   程式每次啟動都會檢查 data 資料夾，不存在就自動建立。
   關掉瀏覽器後系統仍在背景執行，再雙擊 exe 會直接開啟網頁；要結束系統請按網頁左下角「結束系統」。
4. 在「總覽」最上方輸入社區名稱、上傳社區圖示。
5. 「基本設定 → 銀行帳戶與期初餘額」：
   - 自訂名稱（例如「管理費－永豐」）、輸入完整帳號、期初餘額與期初日期。
   - 只有一個銀行帳戶時，管理費撥款自動轉入它；有多個銀行帳戶時，請在「管理費轉入」欄指定。
6. 接著依【建立戶別（全新狀態）】的步驟建立戶別與每月應繳。還沒有戶別時，「戶別與月費」與匯入頁會顯示這幾個步驟（完成的自動打勾），總覽的「待辦事項」也會提示下一步。

【建立戶別（全新狀態）】
1. 從智生活後台「繳費單列表」匯出「管理費匯入範本」Excel（一戶一列，有戶別代碼、所有權人與各收費項目）。
2. 到「匯入智生活報表 → 每月應繳報表」選擇這個檔案。第一次匯入只建立戶別與所有權人：
   - 下方列出檔案內所有戶別，預設全部建立，戶別一律使用智生活的「戶別代碼」（例如 (A01-02)35號2樓之1）。
   - 不需要管理的戶別（例如管理室、公設）勾選「排除」。可用「新戶別」「排除」篩選，或搜尋戶別、所有權人。
   - 按「建立戶別」。
3. 到「戶別與月費 → 基準與費率」建立費率方案（例如坪數費依坪數、汽車位清潔費固定金額），
   勾選戶別套用方案、填坪數、加收清潔費、設定季繳／年繳。
4. 回到「每月應繳報表」再匯入同一份範本：帳單項目對應到基準、和基準不同的逐戶選擇，確認匯入就建立每月應繳。
5. 到「基本設定 → 戶數與銷帳」確認總戶數與帳務起始月。
沒有智生活範本時，也可以在「戶別與月費 → 基準與費率」最下方逐戶「新增戶別」，所有權人點表格內的名字設定。

【結束系統】
系統在背景執行，沒有視窗可以關。要結束時請按網頁左下角「結束系統」（會先存好資料）；
電腦關機或登出時也會自動結束。更新新版時不必先結束，執行新版會自動接手。

【換電腦】
把整個「社區帳務管理」資料夾（含 data）壓縮帶到新電腦，解壓縮後執行「社區帳務管理.exe」即可。

【更新到新版本】
把新版壓縮檔解壓縮到同一個資料夾，覆蓋舊的程式檔即可。
新版壓縮檔裡沒有 data 資料夾，不會蓋掉你的資料。更新前仍建議先把 data 資料夾另外複製一份。

【每月應繳（帳單）】
每月應繳只來自「匯入智生活報表 → 每月應繳報表」（智生活管理費匯入範本），不能手動建立或修改。
1. 先在「戶別與月費 → 基準與費率」設定每戶的基準（基準只在匯入每月應繳報表、入帳報表時拿來比對）：
   - 費率方案：例如「坪數費」（依坪數）、「汽車位清潔費」「機車位清潔費」。方案名稱就是「繳費項目」。
   - 每戶套用一個方案（或個別金額），是這戶的主要費用（例如坪數費）；其他項目用「加收」加入，可設定數量（例如 2 個機車位）。
   - 繳費週期：月繳、雙月繳、季繳、半年繳、年繳，並自訂從幾月開始（例如年繳 7 月起）。
     帳單只在週期的第一個月出現時，會把基準分到週期內每個月；不是週期第一個月的帳單不會匯入並提醒你確認。
2. 匯入智生活的管理費匯入範本 Excel，匯入前會先檢查兩件事：
   ① 帳單項目要對應到基準費率（項目名稱前的「11月」等月份會自動去掉）。
     名稱相同自動對應；不同的（例如「腳踏車清潔費」→「腳踏車位清潔費」）要選擇一次，之後自動套用。
     另外三種對應：「逾期」（例如「10月未繳管理費」「前期未繳」，不列為應繳）、
     「預繳沖銷」（例如「年繳沖銷」「預繳沖銷」，不減少應繳，由系統已收的年繳／預繳款銷帳；系統沒有這戶的預繳款時才照帳單減少應繳）、
     「照帳單」（例如「委員減免」，照帳單金額列入，不比對基準）。
     有任何項目對應不起來就不能匯入。對應表在「基準與費率」最下方，可以修改或刪除。
   ② 逐戶逐項和基準比對，金額不同的會全部列出來，每一筆要選：
     · 更新基準：這戶這項的基準改成帳單金額（依坪數的方案會改坪數，倍數會改數量），本期應繳照帳單。
     · 不更新：基準不變，本期應繳照基準，多出的部分視為帳單內含逾期。
     可以點項目名稱只看那一項，或按「這項全部更新基準／不更新」批次選擇。全部選完才能匯入。
   ③ 逐戶比對所有權人，不同的選「從帳單月份起變更」或「不變更」（見【所有權人變更】）。
   另外可以在「檔案內的戶別」勾選要排除的戶別（見【排除與加回戶別】）；新戶別這次只建立戶別，設定基準後再匯入一次。
3. 逾期不會重複計算：逾期項目和「不更新」多出的部分合計為帳單內含逾期，先對應系統既有的欠款；
   系統沒有的（例如啟用本系統前的欠款）記為上個月的「前期欠款」；系統欠款比帳單多時會提醒，可能有繳費還沒匯入。
4. 已匯入的月份保留當時的基準，之後調漲或調降只影響之後匯入的月份；重新匯入同一個月也沿用當時的基準，
   除非勾選「已匯入過的月份改用目前基準重新比對」。
5. 「戶別與月費 → 每月應繳」（打開就是這一頁）只能查看：每戶的繳費週期、本期基準、智生活帳單、帳單內含逾期、本月應繳與提醒。

【帳務起始月】
起始月之前的應繳不會銷帳。匯入比起始月更早的每月應繳報表時，起始月會自動往前改；
匯入比起始月更早的入帳報表時，匯入頁會提示並可一鍵把起始月往前改（請在按「確認匯入」前先改）。

【每月作業流程】
1. 「匯入智生活報表 → 每月應繳報表」匯入當月的管理費匯入範本（建立／更新每月應繳）。
2. 「匯入智生活報表 → 入帳報表」匯入智生活入帳報表（繳費紀錄）。每份報表上方的「預計入帳日」就是這份報表所有款項的入帳日，
   入帳金額採用報表的「入帳金額」，並會核對「撥款金額」與「撥款帳號」。有交易序號的資料重複匯入時，金額或日期有變動才會更新；
   金額可為負數（退款、沖銷）。
   匯入時若某戶繳費金額與帳單金額（本月應繳＋帳單內含逾期）不同（多繳或少繳），會跳出確認視窗。
   如果金額剛好等於上個月還沒繳清的帳單（例如跨月才入帳、或清潔費調漲前的帳），一定要先選「銷上個月」或「銷這個月」才能完成匯入。
   其他情況可選「系統自動（先銷逾期）」「只銷本期」，或自行勾選要銷的月份（含逾期月份）並填寫金額，
   也可以自行填寫說明（會記在這筆繳費的備註）。
3. 「撥款對帳」：入帳日一律來自智生活入帳報表的「入帳日期」，依入帳日＋繳費方式分組。
   拿存摺比對金額，相符就按「核對相符」，日期不同就填實際日期。
   報表上還沒有入帳日的款項列為在途存款，之後重新匯入有入帳日的報表會自動更新。
4. 「收支記帳」：登錄支出、利息、公共基金提撥等（金額可為負數，例如退款、沖銷）。
5. 「月結／在途存款」：月報依序為收支明細表、管理費入帳及在途存款、結存表。
   檢查後按「匯出 Excel」→「結帳鎖定」。列印請按「列印月報／管理費銷帳 →」到「收支報表」。
6. 「收支報表」：月報（本月＋本年累計）或年報（1～12 月＋全年），表格與月報同樣彩色（收入藍、支出橘、結餘黃）。
   月報與「月結」的收支明細表同一格式：收入在左、支出在右；年報欄位多，收入與支出改為上下排列。
   選月報時：
   「列印月報」印出彩色「財務收支總表」：本期收入與本期支出左右並列，分固定／非固定（在「基本設定 → 收支科目」勾選），
   接著是本期損益、帳戶匯總與簽章欄。管理費收入會依項目拆成收入、預收款、逾期、暫收款。
   「列印管理費銷帳」另外印出管理費繳費明細：本月繳費紀錄（已繳，含銷帳月份）與截至本月尚未繳清的應繳（未繳，每個月分開列出）。
   頁面下方的「管理費銷帳」可看本月應收、已銷帳、未繳統計與明細。
   選年報時按「列印年報」，印出 1～12 月與全年的收支報表並附簽章欄（A4 橫印）。

【欠費／銷帳（逐月銷帳）】
- 每筆繳款依序銷帳：手動指定 → 依期別（先銷當月）→ 從最早未繳清的應繳月份往後銷；銷不完的列為暫收，
  之後月份的應繳建立時會自動銷帳。負數繳款（退款）會先沖暫收，再從最近已銷的月份往回沖。
- 「繳費紀錄」每筆繳費右邊有「調整銷帳」，可直接指定這筆要銷哪幾個月（含逾期月份）；
  入帳日只能看，對存摺請到「撥款對帳」。
- 「戶別明細」列出每戶期間應繳、已銷帳、未繳期數、期間繳款、預繳／暫收、已繳至哪個月；
  點戶別開啟帳卡，可列印給住戶，也可「調整銷帳」手動指定。
- 收入：住戶繳的錢（含預繳）在收款當月全額列入收入；銷帳：每個月只銷當月應繳。

【在途存款】
繳費當月月底前沒有撥入銀行的款項，就是該月的在途存款（入帳日在下個月以後，或報表還沒有入帳日）。
系統依每筆繳費的月份與入帳日自動判斷；下個月撥款後自動沖銷。

【零用金】
- 「零用金」頁逐筆記錄零用金支出（日期、項目、金額、店家、備註），這些明細不會出現在收支表。
  項目從「基本設定 → 收支科目 → 零用金科目」選擇（可新增、刪除、改名、拖拉排序）；
  選「其他」時會自動出現輸入框，輸入實際項目（例如電池），明細顯示為「其他：電池」。
- 在零用金頁上方設定「零用金總額」（定額零用金）。明細的「餘額」從總額開始，每筆支出扣除、撥補入帳時加回，
  每月的上月結餘接續前面所有月份；餘額不足時會以紅字提醒。
- 每月按「產生零用金撥補」，以當月零用金使用總額產生一筆支出「零用金撥補」（從選定的銀行帳戶），
  收支表的支出只會出現這一筆；之後補登零用金時按「更新撥補金額」。

【費率方案依坪數計算】
- 費率方案的計算方式可選「固定金額」或「依坪數計算」：月費＝每坪單價 × 坪數（四捨五入到元）。
- 戶別的坪數在「戶別與月費」填寫，修改坪數或單價時月費會自動重算。

【帳戶與轉帳】
- 選月份後，先列出每個帳戶的上月結存、本月存入、本月支出、本月結存；
  下方每個帳戶各有一張變動紀錄，逐筆列出智生活撥款入帳（同一天合併一筆）、收入、支出、轉入、轉出與累計餘額。
- 「帳戶間轉帳」：選日期、轉出帳戶、轉入帳戶、金額與用途（例如公共基金提撥、定存），
  兩個帳戶的變動紀錄會同時出現這筆轉帳。可匯出 Excel（每個帳戶一個工作表）或列印。
  零用金不列入轉帳選項（零用金撥補請到「零用金」產生）。哪些帳戶排除轉帳，可在「基本設定 → 銀行帳戶與期初餘額」的「排除轉帳」欄勾選。
- 總覽最上方顯示本月總收入、本月總支出、本月結餘與銀行帳戶總餘額（點擊可看帳戶變動紀錄）。

【預收款與暫收款】
- 預收款：已繳、而且已經銷到下個月以後的應繳（例如一次繳 10～12 月）。
- 暫收款：已繳、但還沒有應繳可以銷帳（例如該月份的每月應繳還沒匯入，或多繳）。
  建立對應月份的每月應繳後，暫收款會自動銷帳；總覽會提醒目前有多少暫收款。

【排除與加回戶別】
不需要管理的戶別（例如管理室、公設）可以排除。排除的戶別不列入應繳、欠費與銷帳，之後匯入範本也會自動略過，已匯入的繳費紀錄不會刪除。
- 匯入時排除：匯入每月應繳報表時，下方「檔案內的戶別」勾選「排除」；沒有勾選的全部匯入。原本已排除的戶別會預設勾選，取消勾選就是加回。
- 之後排除：「戶別與月費 → 基準與費率」勾選戶別後按「排除」。
- 加回或永久刪除：「基本設定 → 已排除的戶別」。

【所有權人變更】
戶別是固定的，所有權人可能會換人。所有資料都跟著戶別走，所有權人依月份記錄：
1. 每次匯入每月應繳報表，都會逐戶比對帳單上的所有權人和系統在「帳單月份」的所有權人。
   不同的會列出來，每一戶要選「從帳單月份起變更」或「不變更」（例如寫法不同但是同一人），全部選完才能匯入；也可以按「全部…」批次選擇。
2. 變更不會回溯：只影響帳單月份與之後，之前月份的每月應繳、帳卡、管理費銷帳、未繳明細仍顯示原所有權人。
3. 往回查詢：
   - 「戶別與月費 → 每月應繳」選哪個月就顯示那個月的所有權人（和目前不同時會標示「現為 …」）。
   - 帳卡上方列出所有權人紀錄，逐月銷帳多一欄所有權人。
   - 「戶別明細」有變更過的戶別標示「曾變更」；搜尋舊所有權人的名字也找得到這一戶。
4. 手動修改：「戶別與月費 → 基準與費率」點所有權人，可以查看紀錄、新增變更（選生效月份）、修正錯字或刪除一筆變更。

【報表簽章欄】
「基本設定 → 報表簽章欄」可自訂最多 10 位，每位可放在第 1 行或第 2 行。

【注意事項】
- 資料只存在這台電腦的 data 資料夾，不會上傳到網路。
- 請定期把 data 資料夾或「備份與還原 → 下載完整備份」另存到隨身碟或雲端。
- 要回到某一天的資料：「備份與還原 → 還原」選 data\backups 裡的檔案。
- 畫面支援 1280×720 到 4K 解析度，文字大小會依螢幕寬度自動調整。
