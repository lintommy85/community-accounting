社區帳務管理 使用說明
====================

【資料夾結構】
社區帳務管理\
  社區帳務管理.exe      ← 雙擊執行
  使用說明.html         ← 圖文版使用說明（用瀏覽器開啟）
  使用說明.txt
  data\                 ← 第一次執行時自動建立，所有紀錄與設定都存在這裡
    ledger.json         ← 主要資料檔（每次修改自動儲存）
    backups\            ← 每天第一次存檔前自動保留前一版，最多 60 份

【第一次使用】
1. 把「社區帳務管理」資料夾放到電腦上，例如 D:\社區帳務管理（不要放在壓縮檔裡直接執行）。
2. 雙擊「社區帳務管理.exe」。第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」，
   請按「其他資訊」→「仍要執行」。防毒軟體（例如 PC-cillin）若封鎖，請把「社區帳務管理」資料夾加入例外清單。
3. 系統會在背景執行，並自動開啟系統視窗：用電腦內建的 Microsoft Edge 以「應用程式模式」開啟，
   是獨立的視窗、沒有網址列和分頁，用起來就像一般程式（沒有 Edge 時改用 Chrome，兩者都沒有才用預設瀏覽器）。
   第一次開啟會播放使用說明動畫（之後可在「基本設定」重新播放）。
   程式每次啟動都會檢查 data 資料夾，不存在就自動建立。
   直接關掉系統視窗時，系統仍在背景執行，再雙擊 exe 會重新開啟視窗；要結束系統請按左下角「結束系統」。
4. 在「總覽」最上方輸入社區名稱、上傳社區圖示（要移除圖示請到「基本設定 → 社區名稱與圖示」）。
   畫面預設為深色，右上角可以切換「淺色／深色」；報表與列印一律維持原本的配色。
   左邊選單最上方的按鈕可以把選單收合成只剩圖示（滑鼠移到圖示上會顯示名稱），再按一次展開。
   「撥款對帳」旁邊的數字，是已到預計撥款日、還沒拿存摺核對的撥款筆數。
5. 「基本設定 → 銀行帳戶與期初餘額」：
   - 自訂名稱（例如「管理費－永豐」）、輸入完整帳號、期初餘額與期初日期。
   - 只有一個銀行帳戶時，管理費撥款自動轉入它；有多個銀行帳戶時，請在「管理費轉入」欄指定。
6. 接著依【建立戶別（全新狀態）】的步驟建立戶別與每月應繳。還沒有戶別時，「戶別與月費」與匯入頁會顯示這幾個步驟（完成的自動打勾），總覽的「待辦事項」也會提示下一步。

【建立戶別（全新狀態）】
1. 從智生活後台「繳費單列表」匯出「管理費匯入範本」Excel（一戶一列，有戶別代碼、所有權人與各收費項目）。
2. 到「匯入智生活報表 → 每月應繳報表」選擇這個檔案。第一次匯入只建立戶別與所有權人：
   - 下方列出檔案內所有戶別，預設全部建立，戶別一律使用智生活的「戶別代碼」（例如 (A01-02)35號2樓之1）。
   - 不需要管理的戶別（例如管理室、公設）勾選「排除」。可用「新戶別」「排除」篩選，或搜尋戶別、所有權人。
   - 按「建立戶別」。
3. 到「戶別與月費 → 基準與費率」建立費率方案（例如坪數費依坪數、汽車位清潔費固定金額），
   勾選戶別套用方案、填坪數、加收清潔費、設定季繳／年繳。
4. 回到「每月應繳報表」再匯入同一份範本：帳單項目對應到基準、和基準不同的逐戶選擇，確認匯入就建立每月應繳。
   第一次建立每月應繳時，按「確認匯入」會先問「要先建立期初預收款嗎？」：
   啟用前有住戶已年繳、預繳的，選「要建立期初預收款」會跳到「戶別與月費 → 期初預收款」，輸入完再回來匯入同一份檔案；沒有的選「不需要，直接匯入」。
5. 到「基本設定 → 戶數與銷帳」確認總戶數與帳務起始月。
沒有智生活範本時，也可以在「戶別與月費 → 基準與費率」最下方逐戶「新增戶別」，所有權人點表格內的名字設定。

【結束系統】
系統在背景執行，直接關掉系統視窗不會結束。要結束時請按左下角「結束系統」（會先存好資料，系統視窗也會自動關閉）；
電腦關機或登出時也會自動結束。更新新版時不必先結束，執行新版會自動接手。

【換電腦】
把整個「社區帳務管理」資料夾（含 data）壓縮帶到新電腦，解壓縮後執行「社區帳務管理.exe」即可。

【更新到新版本】
把新版壓縮檔解壓縮到同一個資料夾，覆蓋舊的程式檔即可。
新版壓縮檔裡沒有 data 資料夾，不會蓋掉你的資料。更新前仍建議先把 data 資料夾另外複製一份。

【每月應繳（帳單）】
每月應繳只來自「匯入智生活報表 → 每月應繳報表」（智生活管理費匯入範本），不能手動建立或修改。
1. 先在「戶別與月費 → 基準與費率」設定每戶的基準（基準只在匯入每月應繳報表、入帳報表時拿來比對）：
   - 費率方案：例如「坪數費」（依坪數）、「汽車位清潔費」「機車位清潔費」。方案名稱就是「繳費項目」。
   - 每戶套用一個方案（或個別金額），是這戶的主要費用（例如坪數費）；其他項目用「加收」加入，可設定數量（例如 2 個機車位）。
   - 方案表的「套用戶數」是幾戶，「總數量」是數量加總（例如有 2 個車位的戶算 2；依坪數的方案是坪數加總），可以拿來和實際車位數核對有沒有漏設或設錯。
   - 繳費週期：月繳、雙月繳、季繳、半年繳、年繳，並自訂從幾月開始（例如年繳 7 月起）。
     帳單只在週期的第一個月出現時，會把基準分到週期內每個月；不是週期第一個月的帳單不會匯入並提醒你確認。
   - 跨月帳單自動辨識：月繳戶的帳單金額剛好是每月基準的 2、3、6、12 倍，或項目寫了月份區間（例如「1~12月管理費」），
     匯入時會列出來讓你選「拆成 N 個月」（拆到從帳單月份起的 N 個月，並把這戶改成對應的繳費週期）或「只算這個月」，選完才能匯入。
     如果智生活把逾期直接加在同一個項目裡，金額剛好是兩倍時也會被列出，這時請選「只算這個月」。
     帳單月份一律取「繳費開始日期」；「繳費結束日期」是繳費期限，不用來判斷涵蓋幾個月。
2. 匯入智生活的管理費匯入範本 Excel，匯入前會先檢查兩件事：
   ① 帳單項目要對應到基準費率（項目名稱前的「11月」等月份會自動去掉）。
     名稱相同自動對應；不同的（例如「腳踏車清潔費」→「腳踏車位清潔費」）要選擇一次，之後自動套用。
     另外五種對應：「逾期」（例如「逾期汽車清潔費」「10月逾期」「10月未繳管理費」「前期未繳」，不列為應繳；
      名稱有「逾期」「未繳」「欠繳」「欠款」「前期」的會直接對應到逾期，不用選，也不會和基準比對）、
     「沖銷」（住戶年繳、預繳、溢繳後，帳單上用來扣抵的負數項目，例如「年繳沖銷」「預繳沖銷」，各社區名稱可能不同；
      不減少應繳，而是用沖銷金額從這戶的預收款扣除（含「期初預收款」），優先於銷舊欠；預收款不夠時，不足的部分照帳單減少應繳，不會算成逾期；之後補輸入期初預收款會自動改由預收款沖銷。
      匯入預覽的說明欄會列出每戶扣除前、後的預收款）、
     「照帳單」（例如「委員減免」，照帳單金額列入，不比對基準）、
     「罰款」與「裝潢保證金」（不列入每月應繳、不算欠費，只記在那戶的帳卡；見【罰款與裝潢保證金】）。
     有任何項目對應不起來就不能匯入。「基本設定 → 帳單項目對應」（最下方）列出所有帳單項目的對應：
     同名自動對應的與選過的都在裡面，並顯示對應到的費率方案（怎麼算、幾戶套用）或逾期／沖銷／照帳單的處理方式，可以修改、刪除或事先新增。
   ② 還沒設定基準（每月基準 0）的戶別這次不匯入應繳，也不會用帳單金額建立基準；請先在「基準與費率」套用方案或輸入個別金額，再匯入一次。
   ③ 逐戶逐項和基準比對，金額不同的會全部列出來，每一筆要選：
     · 更新基準：這戶這項的基準改成帳單金額（依坪數的方案會改坪數，倍數會改數量），本期應繳照帳單。
     · 不更新：基準不變，本期應繳照基準，多出的部分視為帳單內含逾期。
     可以點項目名稱只看那一項，或按「這項全部更新基準／不更新」批次選擇。全部選完才能匯入。
   ④ 逐戶比對所有權人，不同的選「從帳單月份起變更」或「不變更」（見【所有權人變更】）。
   另外可以在「檔案內的戶別」勾選要排除的戶別（見【排除與加回戶別】）；新戶別這次只建立戶別，設定基準後再匯入一次。
3. 逾期不會重複計算：逾期項目和「不更新」多出的部分合計為帳單內含逾期，先對應系統既有的欠款；
   系統沒有的（例如啟用本系統前的欠款）記為上個月的「前期欠款」；系統欠款比帳單多時會提醒，可能有繳費還沒匯入。
4. 已匯入的月份保留當時的基準，之後調漲或調降只影響之後匯入的月份；重新匯入同一個月也沿用當時的基準，
   除非勾選「已匯入過的月份改用目前基準重新比對」。
5. 「戶別與月費 → 每月應繳」（打開就是這一頁）只能查看：每戶的繳費週期、本期基準、智生活帳單、帳單內含逾期、本月應繳與提醒。

【帳務起始月】
起始月之前的應繳不會銷帳。匯入比起始月更早的每月應繳報表時，起始月會自動往前改（帳單拆出的「前期欠款」不算，不會因此改起始月）。
入帳報表裡期別在起始月之前的繳款（例如從 11 月開始記帳，報表裡有 10 月管理費），繳的是起始月前的帳單：
這些月份沒有應繳，所以不銷帳、不會拿去銷 11 月，也不列預收或暫收；收入照樣列入繳費當月的「補繳以前月份」，
帳卡上標示「起始月前的帳單，不銷帳」。11 月帳單拆出的 10 月「前期欠款」仍會由 10 月期別的繳款銷帳。
要從更早的月份開始記帳，請先匯入那個月的每月應繳報表（起始月會自動往前改），10 月的繳款就會銷到 10 月。

【每月作業流程】
1. 「匯入智生活報表 → 每月應繳報表」匯入當月的管理費匯入範本（建立／更新每月應繳）。
2. 「匯入智生活報表 → 入帳報表」匯入智生活入帳報表（繳費紀錄）。每份報表上方的「預計入帳日」就是這份報表所有款項的入帳日，
   入帳金額採用報表的「入帳金額」，並會核對「撥款金額」與「撥款帳號」。有交易序號的資料重複匯入時，金額或日期有變動才會更新；
   金額可為負數（退款、沖銷）。
   預覽會逐筆列出：同一張收據單號已經匯入過的標示「已匯入過」，不會重複新增（同一份報表上傳多次也安全）；
   還沒匯入的預設「新增」，不要新增的取消勾選。同一戶、同期別已經有相同金額、而且合計超過這期帳單的，會標示「可能重複」，請確認後決定。
   同一戶分好幾筆繳（例如應繳 3,000 分 3 筆匯款）會全部新增並依序銷帳，合計剛好就不用確認；超過應繳的部分列入這戶的預收款。
   匯入時把同一戶、同期別的繳費加起來（含之前已匯入的），和帳單金額（本月應繳＋帳單內含逾期）比對：
   分好幾筆繳、合計剛好等於帳單的不用確認；合計不同（多繳或少繳）時，只針對讓合計超過帳單的那一筆、或少繳時的最後一筆跳出確認視窗。
   如果金額剛好等於上個月還沒繳清的帳單（例如跨月才入帳、或清潔費調漲前的帳），一定要先選「銷上個月」或「銷這個月」才能完成匯入。
   其他情況可選「系統自動（先銷逾期）」「只銷本期」，或自行勾選要銷的月份（含逾期月份）並填寫金額，
   也可以自行填寫說明（會記在這筆繳費的備註）。
3. 「撥款對帳」：入帳日一律來自智生活入帳報表的「入帳日期」，依入帳日＋繳費方式分組。
   拿存摺比對金額，相符就按「核對相符」，日期不同就填實際日期。
   報表上還沒有入帳日的款項列為在途存款，之後重新匯入有入帳日的報表會自動更新。
4. 「收支記帳」：登錄支出、利息、公共基金提撥等（金額可為負數，例如退款、沖銷）。
5. 「月結／在途存款」：月報依序為收支明細表、管理費入帳及在途存款、結存表。
   檢查後按「匯出 Excel」→「結帳鎖定」。列印請按「列印月報／管理費銷帳 →」到「收支報表」。
6. 「收支報表」：月報（本月＋本年累計）或年報（1～12 月＋全年），表格與月報同樣彩色（收入藍、支出橘、結餘黃）。
   月報與「月結」的收支明細表同一格式：收入在左、支出在右；年報欄位多，收入與支出改為上下排列。
   選月報時：
   「列印月報」印出彩色「財務收支總表」：本期收入與本期支出左右並列，分固定／非固定（在「基本設定 → 收支科目」勾選；匯入的管理費分兩個勾選：「本期收入列為固定收入」與「逾期、預收、暫收也列為固定收入」），
   接著是本期損益、帳戶匯總與簽章欄。管理費收入會依項目拆成收入、預收款、逾期、暫收款。
   「列印管理費銷帳」另外印出管理費繳費明細：本月繳費紀錄（已繳，含銷帳月份）與截至本月尚未繳清的應繳（未繳，每個月分開列出）。
   「列印預收款項銷帳紀錄」印出逐戶的預收款增減（上月底＋本月新增－本月沖銷＝月底）與本月由預收款沖銷的明細
   （預收款來源、沖銷方式：帳單沖銷／依期別／自動銷帳）。頁面下方的「預收款項」可看彙總與明細。
   頁面下方的「管理費銷帳」可看本月應收、已銷帳、未繳統計與明細。
   選年報時按「列印年報」，印出 1～12 月與全年的收支報表並附簽章欄（A4 橫印）。

【欠費／銷帳（逐月銷帳）】
- 每筆繳款依序銷帳：手動指定 → 依期別（先銷當月）→ 帳單沖銷（從預收款扣除）→ 從最早未繳清的應繳月份往後銷；
  銷不完的是多繳，列為這戶的預收款（期別的應繳還沒匯入時列為暫收款），之後月份的應繳建立時會自動銷帳。
  期別在帳務起始月之前、那些月份又沒有應繳的繳款不銷帳（見【帳務起始月】）。
  負數繳款（退款）會先沖還沒銷到的款項，再從最近已銷的月份往回沖。
- 「繳費紀錄」每筆繳費右邊有「調整銷帳」，可直接指定這筆要銷哪幾個月（含逾期月份）；
  入帳日只能看，對存摺請到「撥款對帳」。
- 「戶別明細」列出每戶期間應繳、已銷帳、未繳期數、期間繳款、預繳／暫收、已繳至哪個月；
  點戶別開啟帳卡，可列印給住戶，也可「調整銷帳」手動指定。
- 收入：住戶繳的錢（含預繳）在收款當月全額列入收入；銷帳：每個月只銷當月應繳。

【在途存款】
繳費當月月底前沒有撥入銀行的款項，就是該月的在途存款（入帳日在下個月以後，或報表還沒有入帳日）。
系統依每筆繳費的月份與入帳日自動判斷；下個月撥款後自動沖銷。

【零用金】
- 「零用金」頁逐筆記錄零用金支出（日期、項目、金額、店家、備註），這些明細不會出現在收支表。
  項目從「基本設定 → 收支科目 → 零用金科目」選擇（可新增、刪除、改名、拖拉排序）；
  選「其他」時會自動出現輸入框，輸入實際項目（例如電池），明細顯示為「其他：電池」。
- 在零用金頁上方設定「零用金總額」（定額零用金）。明細的「餘額」從總額開始，每筆支出扣除、撥補入帳時加回，
  每月的上月結餘接續前面所有月份；餘額不足時會以紅字提醒。
- 每月按「產生零用金撥補」，以當月零用金使用總額產生一筆支出「零用金撥補」（從選定的銀行帳戶），
  收支表的支出只會出現這一筆；之後補登零用金時按「更新撥補金額」。

【費率方案依坪數計算】
- 費率方案的計算方式可選「固定金額」或「依坪數計算」：月費＝每坪單價 × 坪數（四捨五入到元）。
- 戶別的坪數在「戶別與月費」填寫，修改坪數或單價時月費會自動重算。

【帳戶與轉帳】
- 選月份後，先列出每個帳戶的上月結存、本月存入、本月支出、本月結存；
  下方每個帳戶各有一張變動紀錄，逐筆列出智生活撥款入帳（同一天合併一筆）、收入、支出、轉入、轉出與累計餘額。
- 「帳戶間轉帳」：選日期、轉出帳戶、轉入帳戶、金額與用途（例如公共基金提撥、定存），
  兩個帳戶的變動紀錄會同時出現這筆轉帳。可匯出 Excel（每個帳戶一個工作表）或列印。
  零用金不列入轉帳選項（零用金撥補請到「零用金」產生）。哪些帳戶排除轉帳，可在「基本設定 → 銀行帳戶與期初餘額」的「排除轉帳」欄勾選。
- 總覽最上方顯示本月總收入、本月總支出、本月結餘與銀行帳戶總餘額（點擊可看帳戶變動紀錄）。

【逾期款項歸類】
- 收支報表選月報時，如果這個月有繳款銷到以前月份（逾期），下方會出現「逾期款項」：
  逐筆列出哪一戶、繳費日、銷了哪個月、哪個應繳項目、金額，以及那個月的應繳內容。
- 每一筆要輸入「報表科目」，也就是月報（財務收支總表）上顯示的名稱，例如「10月逾期汽車清潔費」；
  可以從下拉選以前用過的名稱，或按「未歸類的套用建議名稱」一次填好（例如「10月逾期坪數費」）。
- 科目相同的，在「月報上的逾期科目」選擇「合併成一筆」（預設）或逐筆列出。月報上一律不顯示戶別。
- 還有沒歸類的逾期款項時，那幾列會標成黃色，畫面上方也會提醒；這時按「列印月報」會跳出提示，不能列印。
- 「列印逾期銷帳明細」印出逐戶的逾期明細（戶別、所有權人、繳費日、逾期月份、應繳項目、報表科目、金額），
  同一戶只在第一行顯示戶別與所有權人；最下方一樣套用「基本設定 → 報表簽章欄」。

【罰款與裝潢保證金】
- 帳單項目對應到「罰款」或「裝潢保證金」的，不列入每月應繳，也不算欠費，只記在那戶的帳卡（「罰款與裝潢保證金」一節）。
- 住戶繳款時，先銷這張帳單的管理費等應繳，剩下的付罰款、保證金；繳款照樣撥入銀行帳戶。
  入帳報表的繳費項目本身就是「裝潢保證金」（或對應到罰款、保證金的項目）時，整筆都算這個款項。
- 報表上罰款列為「罰款收入」，保證金列為「裝潢保證金」（名稱可在裝潢保證金頁修改），都不算管理費收入。
- 「日常記帳 → 裝潢保證金」：
  1. 「保證金費率方案」：每個方案可以有好幾個項目，例如保護費（單筆，直接扣）、清潔費（每日，結算時輸入天數）；
     沒有項目的方案就是「無費率」。這些方案和管理費的費率方案無關。
  2. 選擇戶別（列表中的戶別，或在「選擇戶別」輸入戶別代碼），每戶獨立操作：
     看到目前收到多少保證金、什麼時候入帳；不是透過智生活收的可以「手動登錄」（會記一筆收入存入選擇的帳戶）；
     入帳日期早於帳戶期初日期時會多一個「建立系統前已收」勾選（預設勾選）：這筆已經含在帳戶期初餘額裡，
     只記在這戶當作保證金，不改變帳戶餘額、也不列入收支報表（年報不會多出這筆）；結算退款時照常從帳戶扣款、列入報表；
     填施工開始日、套用費率方案（記下套用當時的內容，之後修改方案不影響這戶）。
  3. 完工後在「結算」輸入每日項目的天數，按「結算」會跳出視窗，顯示保證金、各項扣款與應退金額。
     選擇列入本月或下個月的月報，輸入匯款手續費（預設 0，退款金額＝應退金額－手續費）。
     「手續費在財報上」選擇：單獨呈現（支出「裝潢保證金退款」與「裝潢保證金退款手續費」各一筆），
     或併入退款整筆呈現（只有一筆「裝潢保證金退款」，金額含手續費）；系統會記住上次的選擇。
     報表上不顯示戶別，同一個月有多戶結算時，同一個科目合併成一筆。結算錯了可以在「結算紀錄」取消（月份已結帳要先解除月結）。
  4. 「報表科目名稱」可以修改「裝潢保證金」「裝潢保證金退款」「裝潢保證金退款手續費」的名稱，已建立的分錄與報表會一起更新。
  5. 「基本設定 → 收支科目 → 支出科目」上方可以勾選退款、退款手續費是否列為固定支出；改名後勾選會跟著新名稱。
- 總覽：有收到、還沒結算的裝潢保證金時，會多一格「裝潢保證金」顯示合計，沒有時不顯示。

【合約管理與財產管理】
- 側欄「合約與財產」分類有「合約管理」「財產管理」兩頁；有快到期的項目時，側欄會顯示筆數，總覽的待辦事項也會提醒。
- 合約管理：記錄合約項目、簽約廠商、合約金額與帳務週期（每月／每季／每半年／每年，會換算每年金額）、開始與到期日期。
  到期前 3 個月起，該列一直標成黃色，直到續約後把到期日改成新的日期再儲存。
  不打算續約的合約，勾選該列最後一欄「到期不續約」，到了提醒時間也不會高亮、側欄與總覽也不提醒。
- 財產管理 → 設備與證書：有有效期的設備（例如滅火器、緊急照明電池）或要定期更新的證書（例如昇降機使用許可證），
  到期日精確到日期；到期前 3 個月起，該列一直標成黃色，直到更新到期日。
- 財產管理 → 政府申報：預先載入「透保水檢查」「消防申報」「公安申報」，最近一次申報月份先空白。
  每一項設定「每幾年申報一次」與「幾月底前要完成」，系統算出下次期限：有最近一次申報月份時往後推，還沒填時取今天以後最近的期限月份。
  期限前半年起，該列一直標成黃色，直到更新最近一次申報月份（申報完成當月可直接按「本月已完成申報」）。
  預先載入的週期與月份是一般規定（公安申報每 3 年 3 月底前、消防申報每年、透保水檢查每年 4 月底前），請依所在縣市的公告修改；也可以自行新增申報項目。
- 提醒時間可以在「基本設定 → 到期提醒」分別設定：合約管理、設備與證書、政府申報各自到期前幾個月開始提醒（1～24 個月，預設 3、3、6 個月）。
- 每一項都可以按「展開」修改內容；每次儲存會記一筆修改紀錄（合約到期日、設備證書到期日或申報完成月份，以及修改時間），紀錄太多時可以逐筆刪除。

【預收款與暫收款】
- 預收款：住戶預繳（例如一次繳 10～12 月、年繳）或多繳的款項，含期初預收款。沒有欠繳的住戶多繳多少，都列入這戶的預收款。
  下個月匯入每月應繳時，會自動從預收款銷本月應繳（帳單上有沖銷項目時也一樣從預收款扣除），所以每個月沖銷後會越來越少；
  匯入預覽的說明欄會列出每戶扣除前、後的預收款。
- 暫收款：已繳、但這筆繳費期別的每月應繳還沒匯入（例如先匯入 11 月入帳報表、還沒匯入 11 月應繳），
  匯入對應月份的每月應繳後會自動銷帳；總覽會提醒目前有多少暫收款。
- 待確認款項：匯入入帳報表後、還沒在「撥款對帳」核對相符的繳費。總覽把它們列在「待確認款項」，
  核對相符後才計入預收款與暫收款（點「待確認款項」可直接到撥款對帳）。

【期初預收款】
社區不是全新的，啟用本系統前可能已有住戶一次繳了半年、一年。到「戶別與月費 → 期初預收款」輸入每戶在帳務起始月時還剩多少預繳、尚未沖銷的金額
（可按「依月數計算」輸入剩幾個月，以每月基準乘上月數）。系統會從起始月起依序拿來銷每月應繳，剩下的列為預收款。
智生活帳單上的預繳沖銷（例如「年繳沖銷」）會由這筆預收款銷帳；「沖銷沒有預收款」篩選會列出帳單有沖銷、但目前沒有預收款可以扣的戶別。
匯入時還沒有預收款、照帳單減少應繳的沖銷，事後補輸入期初預收款就會自動改由預收款沖銷（應繳恢復原額），不用重新匯入。
自動改回只用帳單月份之前就有的預收款（期初預收款、之前月份多繳的），當月才繳的款項是繳這期帳單，不會拿來沖銷。
由預收款沖銷的部分仍算在「本月應收管理費」與「以前月份預收轉銷」裡，所以應收會比智生活帳單的本月應繳多；
收支報表的「管理費銷帳」和「戶別與月費 → 每月應繳」會把應收拆成「智生活帳單本月應繳」與「帳單預繳沖銷，由預收款銷帳」兩行，方便和智生活帳單對帳。
帳單上的預繳沖銷如果沒有輸入期初預收款（照帳單扣除），收支報表會另列「帳單預繳沖銷，沒有期初預收款、照帳單扣除」，同時算在應收與已銷帳，所以整筆被沖銷、應繳是 0 的戶也會算進應收戶數；未繳金額不受影響。
三行的戶數每戶只算一次：帳單還有要繳的算在「智生活帳單本月應繳」，只被部分沖銷的戶在沖銷那行標成「另 N 戶部分沖銷，戶數算在上面」，所以三行戶數加起來等於應收戶數。

【排除與加回戶別】
不需要管理的戶別（例如管理室、公設）可以排除。排除的戶別不列入應繳、欠費與銷帳，之後匯入範本也會自動略過，已匯入的繳費紀錄不會刪除。
- 匯入時排除：匯入每月應繳報表時，下方「檔案內的戶別」勾選「排除」；沒有勾選的全部匯入。原本已排除的戶別會預設勾選，取消勾選就是加回。
- 之後排除：「戶別與月費 → 基準與費率」勾選戶別後按「排除」。
- 加回或永久刪除：「基本設定 → 已排除的戶別」。

【所有權人變更】
戶別是固定的，所有權人可能會換人。所有資料都跟著戶別走，所有權人依月份記錄：
1. 每次匯入每月應繳報表，都會逐戶比對帳單上的所有權人和系統在「帳單月份」的所有權人。
   不同的會列出來，每一戶要選「從帳單月份起變更」或「不變更」（例如寫法不同但是同一人），全部選完才能匯入；也可以按「全部…」批次選擇。
2. 變更不會回溯：只影響帳單月份與之後，之前月份的每月應繳、帳卡、管理費銷帳、未繳明細仍顯示原所有權人。
3. 往回查詢：
   - 「戶別與月費 → 每月應繳」選哪個月就顯示那個月的所有權人（和目前不同時會標示「現為 …」）。
   - 帳卡上方列出所有權人紀錄，逐月銷帳多一欄所有權人。
   - 「戶別明細」有變更過的戶別標示「曾變更」；搜尋舊所有權人的名字也找得到這一戶。
4. 手動修改：「戶別與月費 → 基準與費率」點所有權人，可以查看紀錄、新增變更（選生效月份）、修正錯字或刪除一筆變更。

【報表簽章欄】
「基本設定 → 報表簽章欄」可自訂最多 10 位，每位可放在第 1 行或第 2 行。

【注意事項】
- 資料只存在這台電腦的 data 資料夾，不會上傳到網路。
- 請定期把 data 資料夾或「備份與還原 → 下載完整備份」另存到隨身碟或雲端。
- 要回到某一天的資料：「備份與還原 → 還原」選 data\backups 裡的檔案。
- 畫面支援 1280×720 到 4K 解析度，文字大小會依螢幕寬度自動調整。
